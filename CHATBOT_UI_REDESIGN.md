## 🚀 How to Use

### **Desktop**
1. Chat window is always visible on right side
2. Click expand button to make it bigger
3. Type in the large textarea input
4. Press Enter to send (or Shift+Enter for new line)
5. Click minimize to collapse to floating button

### **Mobile**
1. Chat window takes 90% of viewport
2. Textarea auto-grows as you type
3. Full touch-friendly interface
4. Easy to tap buttons and scroll
