# Use-case matrix

This is the single list of what the lab does, where each part runs, which fictional fixture exercises it, how it is checked and what status it has. Other documents link here instead of repeating the list.

## Status words

| Status | Meaning |
| --- | --- |
| `verified-local` | Run on the local stack or a clean local environment in the latest pass. The command and result are in [Verification record](#verification-record). |
| `tested-local` | Automated Java, web or Python tests cover it and passed. Not driven end to end in a browser. |
| `local-mock` | Runs on fictional data through a mock or fixture provider. No live provider is called. |
| `azure-not-run` | An Azure adapter exists. No Azure request was made. Azure is opt-in only. |
| `open` | Missing, partly verified, or blocked. Details are in [Open gaps](#open-gaps). |

All fixtures are fictional (`FIKTIVE DATEN`) unless the row says otherwise. Third-party or privately prepared corpora under `.local/` are not in Git and are not cited as public evidence.

## Open gaps

Listed in the priority order of the enterprise hardening plan.

1. **Telemetry export with redaction.** Local runs work without Azure. The optional traces-only collector allowlists span attributes (`docker-compose.monitoring.yml`, [AI integrations](AI_INTEGRATIONS.md)), and tracing is off by default. Nothing has been exported to Application Insights, and redaction has not been tested end to end.
2. **Retention and deletion.** `DOCUMENT_RETENTION_DAYS` defaults to 30, but no job deletes documents, OCR results, vectors or Nova history. `scripts/retention-lab.mjs` purges only scoped lab history, and it is a dry run unless `--apply` is given. This matches [Reliability lab](RELIABILITY_LAB.md).
3. **`.xlsx` files.** Not implemented. The source says to export to CSV first. Limits for size, sheets, rows, formulas and zip bombs are not written.
4. **Benchmarks.** The RAG benchmark ran on nine prepared PDFs (row 6), and the duplicate, rotation, crop and coordinate checks ran as inspection tests (rows 9–11). There is no combined benchmark for content, page, box, duplicates and OCR against the original crop, and the RAG benchmark uses native PDF text, not Docling or OCR output.
5. **Claim-level checks of the Nova pre-check.** The citation format now holds in every live answer, but the lab's claim checks reject the pre-check suggestion (2 of 3 criteria). Causes: one segment carries one source label, so a sentence that combines figures from two documents cannot cite both; and some affirmative statements carry no citation. Options: allow several labels per segment in the schema, or split sentences by source in the prompt; a larger output budget with a longer time limit; a shorter evidence budget; or a different local model. Each changes quality or latency, so the choice belongs to the project owner.
6. **Browser coverage.** Done on port 3001: sign-in, the workspace in English, German and Vietnamese, the phone-width layout, the Nova composer, and the backend-unavailable state. Not done: an upload through the browser, opening a citation's page or region, an accessibility audit (keyboard, contrast, screen reader), and deliberately triggered timeout and retry states.
7. **UI consolidation.** Partly done: the duplicate "Add documents" link on Reconciliation was removed and its page-tour step now points at the alert list. Still duplicated, not changed: the AI directory on Tasks (about 30 capabilities, from the client catalogue) and the AI task library on AI transparency (11 tasks, from the server catalogue) are two lists; "Add documents" appears on Tasks, Processing & data and Documents & evidence; "Processing details" appears on Documents & evidence and Processing & data; the same nine PDFs are listed on Domain analysis and Research datasets; and Nova has several entry points on Tasks, Domain analysis and Research datasets.
8. **Other containers run as their image defaults.** PostgreSQL, Redis, ClamAV and Qdrant are not hardened the way Ollama is. The credit API, Docling and the ETL worker are not checked for dropped capabilities either.
9. **Azure.** Nothing called. The checklist for Speech, Translator, Voice Live, AI Search, Content Understanding and Prompt Shields is in [AI-103 verification](AI103_VERIFICATION.md#3-azure).
10. **Known vulnerabilities in the Ollama image.** The engine moved from 0.40.6 to 0.40.16 (Ubuntu base unchanged). Trivy: the Go module findings in the `ollama` binary fell from 50 HIGH to 1 HIGH; the two HIGH findings in the Ubuntu packages (an `apt` issue that has a fixed package version) remain, because the image does not upgrade its base packages.
11. **Docker disk space.** During this pass the Docker VM disk filled up once: a layer write failed with "no space left on device", and the credit API could not create its temporary directory. About 17 GB of build cache was pruned, keeping 4 GB. The upstream Ollama image is 4.33 GB because it includes CUDA libraries; the repackaged image drops them.
