# Use-case matrix

This is the single list of what the lab does, where each part runs, which fictional fixture exercises it, how it is checked and what status it has. Other documents link here instead of repeating the list.

## Status words

| Status | Meaning |
| --- | --- |
| `verified-local` | Run on the local stack or a clean local environment. The command and result are in [Verification record](#verification-record). |
| `tested-local` | Automated Java, web or Python tests cover it and passed. Not driven end to end in a browser. |
| `local-mock` | Runs on fictional data through a mock or fixture provider. No live provider is called. |
| `azure-not-run` | An Azure adapter exists. No Azure request was made. Azure is opt-in only. |
| `open` | Missing, partly verified, or blocked. Details are in [Open gaps](#open-gaps). |

All fixtures are fictional (`FIKTIVE DATEN`) unless the row says otherwise. Third-party corpora under `.local/` are not in Git and are not cited as evidence.

## Open gaps

Listed in the priority order of the enterprise hardening plan.

1. **Telemetry export with redaction.** Local runs work without Azure. The optional traces-only collector allowlists span attributes (`docker-compose.monitoring.yml`, [AI integrations](AI_INTEGRATIONS.md)) and tracing is off by default. Nothing has been exported to Application Insights, and redaction has not been tested end to end.
2. **Retention and deletion.** `DOCUMENT_RETENTION_DAYS` defaults to 30, but no job deletes documents, OCR results, vectors or Nova history. `scripts/retention-lab.mjs` purges only scoped lab history, and it is a dry run unless `--apply` is given. This matches [Reliability lab](RELIABILITY_LAB.md).
3. **`.xlsx` files.** Not implemented. The source says to export to CSV first. Limits for size, sheets, rows, formulas and zip bombs are not written.
4. **Benchmarks.** Duplicate occurrence, rotation, crop and coordinate checks now exist as inspection tests (rows 9–11). There is no combined benchmark for content, page, box, duplicates and OCR against the original crop. The RAG corpus benchmark is skipped without `RAG_PDF_CORPUS`.
5. **Nova answers on this CPU.** In this pass Nova generated text but no answer passed the output contract:
   - the pre-check case reached the 420-token output limit (`LocalAiConfiguration`, `numPredict`) after 2,366 prompt tokens, about 4.7 minutes;
   - a single-document case was refused by the citation contract twice (`NON_SOURCE_BRACKET`). The validator was not loosened.
   Options are a larger output budget with a longer timeout, a shorter prompt, or a different local model. Each changes latency or quality, so the choice belongs to the project owner.
6. **Browser checks.** Not run in this pass. The web container cannot bind `127.0.0.1:3000`, which another local development server holds. Keycloak redirects are configured for that port.
7. **UI simplification.** Not started in this pass.
8. **Other containers run as their image defaults.** PostgreSQL, Redis, ClamAV and Qdrant are not hardened the way Ollama is. The credit API, Docling and the ETL worker are not checked for capability drops either.
9. **Azure.** Nothing called. The checklist for Speech, Translator, Voice Live, AI Search, Content Understanding and Prompt Shields is in [AI-103 verification](AI103_VERIFICATION.md#3-azure).
10. **Known vulnerabilities in the pinned Ollama engine.** Trivy reports 50 HIGH findings in the Go modules of the upstream `ollama` 0.40.6 binary and 2 HIGH in the Ubuntu packages of its image. Fixing them means moving the pinned engine version, which changes model behaviour and needs a verification pass. This is not done.
