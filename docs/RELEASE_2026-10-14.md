## Private cloud DATEV library

The operator explicitly approved both fictional publisher pages for cloud testing. `node scripts/azure-vm-lab.mjs references` verifies SHA-256 hashes and prepares `/opt/credit-lab/references`. Java mounts the folder read-only. Vercel proxies the authenticated Java library when local files are absent; both layers reject unknown or altered references. Responses are private and uncached. PDFs, credentials, Terraform state and database dumps stay outside Git.

Preparation does not call AI. Import/analysis requires a separate explicit action. Acceptance uses fictional publisher references only, never real applicant files.

## Release gates and limitations

Backend acceptance is complete. Final master/Vercel and browser results are recorded below after release. Check security workflow results separately; SBOM generation and npm audit are not container-vulnerability certification.

Single VM: no high availability or complete tested off-site disaster recovery. Daily cost-control shutdown remains enabled; it stops login/API/AI, not Vercel. OCR confidence, search rank and lexical overlap are not calibrated accuracy. This verification does not prove every input, viewport, load level or model output is error-free.
