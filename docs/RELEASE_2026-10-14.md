## Private cloud DATEV library

The operator explicitly approved both fictional publisher pages for cloud testing. `node scripts/azure-vm-lab.mjs references` verifies SHA-256 hashes and prepares `/opt/credit-lab/references`. Java mounts the folder read-only. Vercel proxies the authenticated Java library when local files are absent; both layers reject unknown or altered references. Responses are private and uncached. PDFs, credentials, Terraform state and database dumps stay outside Git.

Preparation does not call AI. Import/analysis requires a separate explicit action. Acceptance uses fictional publisher references only, never real applicant files.

## Included improvements

- Original-document-only evidence; no generated payment/bank/benchmark results presented as live data.
- Same-page processing/results, original PDF, page/table evidence and explained OCR recognition scores.
- Clear Azure/local-provider labels and direct AI-directory workflow links.
- Nova guide vs evidence modes, Enter/Shift+Enter, expanded reading area and page-specific tours.
- Persistent feedback, unsent correction/task drafts and versioned reviewer workflow.
- Missing Azure fails explicitly, not with a financial demo answer.
- Feature-branch verification/security workflows; CI supports fresh empty databases.
- Spring Boot 4.1.1 with patched Jackson, Tomcat, Netty and OpenSSL; existing stored evidence keeps its JSON contract.
- Qdrant parsing is explicit across the Jackson 2 persistence / Jackson 3 HTTP boundary.
- Runtime web image contains Node and the standalone application, not unused npm/Corepack package-management dependencies.
- Nova supplements ranked passages with bounded structured fields from selected, original-backed documents. Named-person, page and quarantine checks remain enforced.
- Azure content-filter refusals remain enabled and return a distinct safe message, not a misleading connection error. Diagnostics contain exception categories/status codes only, never provider bodies or credentials.

## Release gates and limitations

`master` and `develop` contain the release. Verification and dependency/image security workflows passed on the released application changes; inspect [Actions](https://github.com/quocvietphung/credit-intelligence-lab/actions) for the current exact commit. SBOM generation and vulnerability scans are not security certification.

Browser acceptance on the canonical production domain: signed out, entered the operator-requested advisor password, signed back in; opened all nine workspace sections; displayed the original DATEV PDF and extracted amounts; queried Qdrant; advanced/closed the seven-step AI Studio tour; sent a Vietnamese Nova question with Enter (Shift+Enter did not submit), received both amounts and opened its citation back to the PDF. No browser console errors were captured in this checked flow. A Vercel error-log query returned no entries; this is not complete monitoring coverage.

Production screenshots show the actual results, Nova and page walkthrough. Publisher PDF pages, passwords and token state are not included in screenshots committed to Git. New synthetic test cases and answer history remain in their authorized cloud/local databases; tests do not purge historical evidence.

Single VM: no high availability or complete tested off-site disaster recovery. Daily cost-control shutdown remains enabled; it stops login/API/AI, not Vercel. OCR confidence, search rank and lexical overlap are not calibrated accuracy. This verification does not prove every input, viewport, load level or model output is error-free.
